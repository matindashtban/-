# دستیار حضور و غیاب معلم — پروژه اندروید

این پروژه نسخه اندرویدی فایل HTML حضور و غیاب است. رابط اصلی درون WebView و از فایل محلی `app/src/main/assets/index.html` اجرا می‌شود؛ بنابراین برای اجرای هسته برنامه به باز کردن مرورگر نیاز نیست.

## ساخت APK با Android Studio

1. Android Studio را نصب و باز کنید.
2. گزینه **Open** را بزنید و پوشه `attendance_android` را انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود و Android SDK Platform 35 نصب باشد.
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** را انتخاب کنید.
5. فایل خروجی در مسیر زیر ساخته می‌شود:

   `app/build/outputs/apk/debug/app-debug.apk`

حداقل نسخه اندروید: Android 7.0 (API 24).

## امکانات اتصال اندروید

- ذخیره‌سازی مرورگر داخلی WebView با DOM Storage فعال.
- انتخاب عکس دانش‌آموز و انتخاب فایل JSON برای بازیابی پشتیبان.
- ذخیره خروجی‌های برنامه از طریق پنجره استاندارد انتخاب محل ذخیره اندروید.
- چاپ گزارش و ذخیره PDF از طریق سرویس چاپ اندروید.
- پشتیبانی از دکمه بازگشت گوشی.

## نکات مهم

- اطلاعات در فضای داده‌های خصوصی برنامه و WebView ذخیره می‌شوند؛ پاک کردن داده‌های برنامه یا حذف آن می‌تواند اطلاعات محلی را حذف کند. به‌طور منظم فایل پشتیبان بگیرید.
- این نسخه همگام‌سازی ابری بین چند گوشی ندارد.
- کتابخانه‌های Excel و ZIP در HTML از CDN بارگذاری می‌شوند؛ برای این دو خروجی و برخی قابلیت‌های وابسته به کتابخانه، اتصال اینترنت لازم است.
- این پروژه هنوز با کلید امضای انتشار (release signing) امضا نشده است. APK ساخته‌شده از نوع debug برای نصب و آزمایش است.

## ساخت خودکار

در مخزن GitHub، پس از قراردادن محتویات این پوشه در شاخه `main`، Workflow موجود در `.github/workflows/android.yml` را می‌توان از بخش Actions اجرا کرد. فایل APK به‌عنوان Artifact قابل دریافت خواهد بود.
